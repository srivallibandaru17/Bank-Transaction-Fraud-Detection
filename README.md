Bank Transaction Fraud Detection using Snowflake

Project Overview

This project focuses on detecting fraudulent bank transactions using Machine Learning in Snowflake.

Dataset

- Dataset Name: PaySim – Synthetic Financial Datasets for Fraud Detection
- Source: Kaggle
- Dataset Link: https://www.kaggle.com/datasets/ealaxi/paysim1
- Problem Type: Binary Classification

Tools and Technologies

- Snowflake
- Snowflake SQL
- Snowflake ML Classification
- Python (for dataset splitting)

Project Workflow

1. Dataset preparation and upload
2. Data exploration using SQL
3. Feature engineering
4. Training and testing data split
5. Machine Learning model creation
6. Model evaluation
7. Fraud prediction

Model Evaluation

- Macro Precision: 0.5688
- Macro Recall: 0.6097
- Macro F1 Score: 0.5845
- Macro AUC: 0.6015
